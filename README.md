# سامانه مدیریت لایسنس دیاگ هوشدار (Hoshdar Diag License Manager)

سامانه تولید و مدیریت کدهای فعالسازی و لایسنس نرم‌افزار خودرویی و دیاگ هوشدار بر پایه رمزنگاری قطعی و غیرقابل جعل **HMAC-SHA256**.  
توسعه داده شده توسط **مهندس نریمانی**.

---

## 🚀 ویژگی‌های کلیدی
- **هسته رمزنگاری قدرتمند (HMAC-SHA256):** تولید کدهای فعالسازی ۸ رقمی عددی و ۱۶ کاراکتری بلوکی با کلید مادر و شناسه سخت‌افزاری دستگاه.
- **پکیج‌های دسترسی خودرویی:**
  - `DPRO`: دیاگ تخصصی پرو (خواندن و پاک کردن DTC، تست عملگرها، پارامترهای زنده)
  - `REMAP`: ریمپ و تیونینگ ECU (جداول سوخت و جرقه، حذف کات‌اف، حذف سنسور اکسیژن)
  - `FLEET`: مانیتورینگ ناوگان (تله‌متری آنلاین، لاگ خطاهای بی‌سیم و جعبه سیاه)
  - `LFT`: نسخه نامحدود طلایی (فعالسازی مادام‌العمر تمامی ماژول‌ها)
- **شبیه‌ساز دیاگ کلاینت (۱۰۰٪ آفلاین):** تست و اعتبارسنجی آنی کدهای فعالسازی بدون نیاز به اینترنت.
- **تاریخچه لایسنس‌ها:** جستجو، فیلتر، تغییر وضعیت، و خروجی اکسل/CSV و JSON.
- **سورس‌کد آماده کلاینت:** کلاس‌های اعتبارسنجی کلاینت آماده کپی به زبان‌های **Kotlin (Android/Compose)** و **Java**.

## 🛠️ نحوه نصب و اجرا (Installation & Run)

```bash
# ۱. کلون ریپازیتوری
git clone https://github.com/RezaNarimani375/Code_Manager.git
cd Code_Manager

# ۲. نصب پکیج‌ها
npm install

# ۳. اجرای محیط توسعه
npm run dev

# ۴. بیلد نسخه نهایی
npm run build
```
